## Масштабирование приложения

Проект состоит из приложения и nosql базы данных.   
В целях повышения производительности применяется вертикальное(увеличение ресурсов) и горизонтальное масштабирование.    
В проекте применяется горизонтальное масштабирование методамами  
-шардирования базы данных;  
-репликации базы данных;    
-кеширования данных;    
-масшабирования приложения (API Gateway и Service Discovery);  
-использование сервиса доставки контента (Content Delivery Network - CDN);
